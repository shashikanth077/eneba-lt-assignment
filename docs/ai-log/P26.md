## Response summary

Frames of the recording show (1) every card and the product page saying "Out of stock", empty homepage rails, and (2) "Categories" opening a tiny cut-off box (just "Action" with a scrollbar) at the top-left. The deployed site could not be reached from this session (network policy), so the diagnosis comes from the video and the code.

1. **Out of stock:** the production database has no game keys (the import file excludes them by design) and the container's start step was off unless two variables were set, so nothing created them. Stock = at least one `available` key. Fix: the start step is now ON by default (`RUN_MIGRATIONS` true, `SEED_ON_START` if-empty): on the next deploy the container creates the keys with the service's own `KEY_ENCRYPTION_KEY` (idempotent; opt out with `false`). If the database is unreachable the container still starts with a warning (unless `RUN_MIGRATIONS` was set explicitly), so `/api/health` can report it. Verified on an imported key-less scratch database: first start seeds 14,391 keys, second skips, opt-out works, unreachable DB behaves as described.
2. **Categories:** the genre dropdown was positioned inside the nav bar, which scrolls sideways (`overflow-x: auto` also clips vertically), so the menu was cut to a sliver. It is now a real side panel (the existing drawer `Modal`) listing "All games" and the genres, closing on choice. A unit test covers it; jsdom cannot see clipping, so a real-browser test checks the panel's height.
3. **End to end before deploy:** new Playwright spec `e2e/browse.spec.ts` (store with prices and no "Out of stock", Categories panel visible and tall, genre filter, game page with a buyable offer table, sign-in from `/login?next=...` returning to the game page with "Add to cart" available) next to the existing purchase spec. Both pass locally against a seeded database. Also vitest 349, lint, tsc, build.

Not done / needs the user: redeploy the backend on Railway (the seeding happens on its next start); the production site itself was not tested by me.
