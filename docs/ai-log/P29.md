## Response summary

Branch `claude/home-sections-currency`. Four new homepage rows, assembled like the existing ones from `home_blocks` (details in docs/HOME_BLOCKS.md): a category shortcut strip (backend block `categories`: Games, the platforms that really have products, top genres), **Recently viewed** (history kept in the visitor's browser, cards fetched through a new `slug[]` filter on `GET /api/products`, so prices/stock are current; hidden with no history), **Recommended for you** (backend block: popularity per euro; same list for everyone, stated as such) and **Upcoming games** (backend block on future release dates, cards show "Releases 17 Nov 2026"). Migration 009 adds the rows and, because demo dates age, schedules a dozen products in the future when none is upcoming (the seeder does the same, idempotently). `HomeLayout` now keeps rows with no endpoint (browser-only blocks).

Language and currency: header button "English EU | EUR" opens an "Update your settings" dialog. Currency (EUR default, USD, GBP, AED) changes displayed catalogue prices; kept in localStorage. **Limits, stated openly:** the rates are fixed demo values, not live; the card is always charged in EUR (cart, checkout and orders stay in EUR and say so); **language offers English only** because the app has no translation layer: real languages need every UI string extracted (not started). Region selection from the reference dialog was not built.

Not built from the screenshots: the banner side tiles, cashback/gift-card categories (this shop sells game keys only), "Show all/See all" buttons.

Verified: PHPUnit 383, Vitest 373, lint, build, Playwright 6 flows (one flaked once under parallel load and passed on rerun) against a locally migrated database.
